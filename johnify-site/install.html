Install

You need two or more ESP32-family boards. Two is enough to test, and each extra board is another chat node or a repeater.

1. Get the files

Download or clone the Johnify repository from GitHub. Everything below runs from the root of that folder.

Open the GitHub repository
git clone https://github.com/Johndinglesin/Johnify.git
cd Johnify

2. Check your board

BoardMAX_ROOMSMAX_MSGS
With PSRAM, such as XIAO ESP32S3 on a PSRAM build24200
ESP32 or ESP32-S3 without PSRAM860
ESP32-S2 or ESP32-C3640

These are MicroPython settings at the top of main.py. Not supported: ESP8266 and Raspberry Pi Pico W, which lack the RAM or ESP-NOW.

3. Put it on the board



Replace PORT with your own serial port. The name differs per computer and can change between flashing and running, so look it up each time. For MicroPython, flash the firmware first and expect fs ls to list all three files. For Arduino, you can also open arduino/Johnify/Johnify.ino in the Arduino IDE. While developing over USB, set USE_WATCHDOG = False.


4. Start chatting
  • Join the Johnify-XXXX Wi-Fi network on your phone
  • Open http://192.168.4.1 in a browser
  • Press Create chat to get a 10-character code


  • Your friend joins their own board and enters the code
  • If the page will not load, turn off mobile data
  • Use the Settings page for repeater mode and diagnostics
