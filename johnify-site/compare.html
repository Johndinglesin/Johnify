Arduino vs MicroPython

Johnify ships as two firmwares. They serve the same web app, speak the same packet format and use the same encryption, so boards running either version can share chats and relay for each other.

What is identical

  • Wi-Fi hotspot name, captive portal and channel 1
  • The web app, served byte for byte
  • The HTTP API and its error codes
  • Packet layout and AES-256-GCM with the same authenticated data
  • Key derivation: 5,000 rounds of SHA-256
  • Duplicate suppression and 4-hop repeater limit
  • Limits: 24 chats per board, 190 bytes of text
  • Saved chat codes and repeater setting in flash

Which to use

Arduino

Choose it if you have a XIAO ESP32S3 and want the fastest crypto and the fewest moving parts: one compiled image, fixed memory use, and a web server that runs separately from the radio.

MicroPython

Choose it for boards other than the XIAO, or if you want to edit and re-upload the web page and settings without recompiling. Check the memory table on the install page for your board.

Cross-compatibility was verified on a computer by building real packets with both codebases and exchanging them in both directions. It has not been run on every board, and the radio has not been tested on real hardware in that check.
