Encrypted group chat that runs without the internet.

Johnify turns ESP32 boards into a local chat network. Each board creates its own Wi-Fi hotspot and serves the chat app. Phones connect with a browser, and the boards relay AES-256-GCM encrypted messages to each other over radio.

Install JohnifySee how it works

What it does

Works anywhere

No infrastructure at all. Boards talk to each other directly, and phones talk only to their nearest board.

Encrypted end to end

Messages use AES-256-GCM with a key derived from a shared chat code. The key never leaves the board or the phone.

Extendable range

Any board can be switched into repeater mode to relay traffic for other chats, without being able to read it.

Specifications

Encryption
AES-256-GCM, key from the chat code
Radio
ESP-NOW broadcast, 2.4 GHz, channel 1
Packet size
60 bytes plus text, 250 maximum
Message limits
190 bytes of text, 12 bytes of name
Repeater
Up to 4 hops
Capacity
24 chats per board, 8 phones per board
Firmware
Arduino (C++) and MicroPython
Version
1.3.0
